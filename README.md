# Notix

Notix is a student management application built with Python and Tkinter, designed to help students organize their academic life. With a simple and intuitive graphical interface, Notix allows users to manage their class schedules, homework assignments, tasks, and academic progress, all in one place.

## Features

- **Class Schedule (Thời Khóa Biểu)**  
  Easily add, edit, and delete subjects for each period and day of the week. View your weekly timetable in a clear tabular format.

- **Homework Manager (Quản Lý Bài Tập)**  
  Keep track of all your homework assignments, set deadlines, mark them as completed, and manage your workload efficiently.

- **Task Manager (Quản Lý Công Việc)**  
  Create and organize tasks with descriptions, deadlines, and priority levels. Filter tasks by priority to focus on what's most important.

- **Academic Progress (Tiến Độ Học Tập)**  
  Log scores for each subject and view your average grades to monitor your academic performance over time.

## Usage

- Launch the application and navigate using the main menu.
- Add or manage schedules, homework, tasks, and scores with simple forms.
- Data is saved locally in `data.json` and persists between sessions.

## Requirements

- Python 3.x
- Tkinter (usually included with Python standard library)

## Run

```bash
python NOTIX (3).py
```
